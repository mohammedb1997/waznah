# PocketBase hooks

هذا المجلد محجوز لقواعد الخادم التي يجب ألا تعتمد على حماية الواجهة فقط.

مهم: أي قاعدة أمنية حرجة يجب تطبيقها على PocketBase/API Rules أو Hook على الخادم؛ إخفاء الزر في `admin.js` ليس حماية.

ابدأ بتقييد قواعد CRUD في PocketBase، ثم أضف audit logging على عمليات التعديل والحذف بعد اختبار الإصدار الحالي من PocketBase لديك.
